# Assis Brechó

Site desenvolvido para apresentar a marca Assis Brechó, especializada em customização de roupas e acessórios.

## 💡 Sobre o projeto

O projeto consiste no desenvolvimento de uma página web para apresentar a marca, divulgar seus serviços e facilitar a comunicação com os clientes.

## 🎯 Motivação

Este projeto foi desenvolvido para uma amiga que possui uma marca de customização de roupas e acessórios.

A ideia surgiu da oportunidade de utilizar meus conhecimentos em desenvolvimento web para ajudar a dar mais visibilidade ao seu trabalho, criando um espaço digital onde as pessoas pudessem conhecer a marca, explorar os serviços oferecidos e solicitar personalizações.

Foi uma oportunidade de transformar uma necessidade real em uma solução digital, colocando em prática meus conhecimentos e desenvolvendo minha experiência na criação de sites.

## ✨ Funcionalidades

- Apresentação da marca e de seus serviços.
- Seção sobre a responsável pelo negócio.
- Integração com Instagram.
- Formulário para solicitação de customizações.
- Direcionamento de pedidos para o WhatsApp.
- Navegação intuitiva.
